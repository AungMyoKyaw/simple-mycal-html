## PWA Features

This application is a Progressive Web App (PWA) with the following features:

- **Installable**: Can be installed on mobile and desktop devices
- **Offline Support**: Works without internet connection using service worker caching
- **Standalone Mode**: Runs in a dedicated window like a native app
- **Responsive**: Optimized for all screen sizes and orientations
